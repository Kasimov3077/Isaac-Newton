Термины

Java
Объектно-ориентированный кроссплатформенный язык программирования, созданный Джеймсом Гослингом в Sun Microsystems и представленный в 1995 году.
Oak
Первое название языка, который позже стал Java. Название дано в честь дуба за окном офиса Гослинга.
Проект «Green»
Проект Sun Microsystems начала 1990-х по созданию ПО для интерактивного телевидения и бытовой электроники, в рамках которого появился Oak.
JVM (Java Virtual Machine)
Виртуальная машина Java: программа, выполняющая байт-код и скрывающая различия между операционными системами.
Байт-код
Промежуточный код, в который компилируется программа на Java; выполняется виртуальной машиной на любой платформе.
JDK (Java Development Kit)
Набор инструментов разработчика Java: компилятор, стандартные библиотеки, отладчик и другие утилиты.
JRE (Java Runtime Environment)
Среда выполнения Java: виртуальная машина и библиотеки, необходимые для запуска готовых программ.
WORA (Write Once, Run Anywhere)
Принцип «написано один раз — работает везде»: одна и та же программа работает на разных платформах.
NeWS (Network-extensible Window System)
Оконная система, разработанная Гослингом в Sun Microsystems; проиграла конкуренцию X Window.
Gosling Emacs
Версия текстового редактора Emacs, написанная Гослингом на языке C и ставшая одним из первых коммерчески успешных продуктов на этом языке.
