Публикации Джеймса Гослинга в основном связаны с языком Java, который он создал. Он является автором и соавтором ключевых технических спецификаций и книг, определивших стандарты этого языка. Ключевые книги и спецификации Наиболее значимые его работы — это фундаментальные труды по языку Java: The Java Language Specification (Спецификация языка Java): Это официальный технический справочник, описывающий синтаксис и семантику языка. Гослинг — соавтор нескольких изданий, включая редакции для Java SE 7 и Java SE 8. The Java Programming Language (Язык программирования Java): Эта книга, написанная в соавторстве с Кеном Арнольдом и Дэвидом Холмсом, служит практическим руководством по программированию на Java. Она выдержала несколько переизданий (с 1-го по 4-е). Другие публикации и статьи Помимо основополагающих книг, в его библиография включает: The Real-Time Specification for Java (Спецификация Java для систем реального времени): Статья 2000 года, написанная в соавторстве с Грегори Боллеллой, посвященная расширению Java для задач, требующих жесткого соблюдения временных рамок. The Feel of Java (Ощущение Java): Статья 1997 года, в которой Гослинг размышляет о философии и дизайне языка. The NeWS Book: Книга, посвященная оконной системе Network extensible Window System (NeWS), разработанной Гослингом в Sun Microsystems. UNIX Emacs: A Retrospective: Статья 1988 года, в которой он оглядывается на опыт создания текстового редактора Gosling Emacs.
